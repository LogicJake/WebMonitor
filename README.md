# 网页监控系统 (Web Monitor v2)

一个功能强大的网页内容监控系统，支持实时监控网页变化并发送通知。

## ✨ 主要功能

### 🔍 智能内容提取
- **多种选择器支持**：XPath、CSS Selector、JSONPath
- **正则表达式二次提取**：对提取结果进行精确过滤
- **自定义请求头**：支持API认证、内容类型指定等

### 📊 灵活的变化检测
- **默认检测**：基于消息模板内容变化
- **自定义条件**：支持6种判断操作符
  - 包含/不包含指定文本
  - 数值大于/小于比较
  - 相比前值增加/减少
- **多条件组合**：按优先级顺序判断，满足任一条件即触发

### 📧 多样化通知方式
- **邮箱通知**：支持SMTP邮件发送
- **Webhook**：自定义HTTP回调
- **钉钉机器人**：企业级即时通知
- **企业微信机器人**：团队协作通知

### 🎨 消息模板系统
- **变量替换**：使用 `{元素名称}` 格式引用提取值
- **默认模板**：自动生成"元素名:值"格式
- **灵活配置**：支持自定义消息格式

### 🧪 实时测试功能
- **配置验证**：测试选择器是否正确提取内容
- **模板预览**：查看消息模板替换效果
- **变化模拟**：验证变化检测逻辑
- **通知测试**：可选择性测试通知发送
- **性能监控**：显示响应时间和执行详情

### 📱 现代化界面
- **响应式设计**：支持桌面和移动设备
- **左右分栏布局**：配置区域和测试区域分离
- **实时反馈**：即时显示操作结果和状态
- **折叠展示**：消息模板和检查内容可折叠查看

## 🛠️ 技术栈

### 后端
- **框架**：Flask + SQLAlchemy
- **数据库**：SQLite（可扩展至其他数据库）
- **网页解析**：requests + lxml + jsonpath
- **任务调度**：多线程后台监控
- **日志系统**：结构化日志记录

### 前端
- **框架**：Vue 3 + Composition API
- **UI组件**：Element Plus
- **构建工具**：Vite
- **路由**：Vue Router
- **状态管理**：响应式数据

## 🚀 快速开始

### 1. 创建通知方式
在"通知管理"中配置邮箱、Webhook或机器人通知。

### 2. 新建监控任务
1. 填写任务名称和监控网址
2. 设置检查间隔（秒）
3. 添加元素选择器：
   - 元素名称：用于标识提取的内容
   - 选择器类型：XPath/CSS/JSONPath
   - 表达式：具体的选择器语法
   - 正则表达式：可选的二次过滤
4. 选择通知方式
5. 设置消息模板（可选）
6. 配置变化判断条件（可选）

### 3. 测试配置
点击"测试任务"按钮验证配置：
- 检查网页是否能正常访问
- 验证选择器是否提取到正确内容
- 预览消息模板效果
- 测试通知发送（可选）

### 4. 启动监控
保存任务后，系统将按设定间隔自动监控。

## 📋 使用示例

### 监控商品价格
```
网址: https://example.com/product/123
选择器: //span[@class="price"]/text()
正则表达式: (\d+\.\d+)
变化条件: price 小于 100
消息模板: 商品价格降至 {price} 元！
```

### 监控库存状态
```
网址: https://api.example.com/stock
选择器: $.data.stock
变化条件: stock 大于 0
消息模板: 商品有库存了！当前库存：{stock}
```

### 监控文章更新
```
网址: https://blog.example.com
选择器: .post-title
变化条件: 内容包含"新文章"
消息模板: 发布了新文章：{title}
```

## 🔧 高级功能

### 自定义请求头
支持添加认证信息、User-Agent等：
```json
{
  "Authorization": "Bearer token123",
  "User-Agent": "Custom Bot 1.0",
  "Accept": "application/json"
}
```

### 变化判断条件
- **包含/不包含**：文本匹配
- **大于/小于**：数值比较
- **增加/减少**：与历史值对比
- **优先级**：按添加顺序判断

### 消息模板变量
- `{元素名称}`：引用选择器提取的值
- 支持多个变量组合
- 默认使用制表符连接所有元素
